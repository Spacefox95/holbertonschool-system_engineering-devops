# Web Infrastructure Design

## Description

This project is focusing on the fundamental concepts of web infrastructure design. This project encourages students to explore various networking and server concepts, including load balancing, DNS, and monitoring systems. By completing this project, I developped a strong understanding of how to design and explain a scalable and secure web infrastructure.

## Concepts

Throughout this project, I learned about the following concepts:

- **Network Basics**
- **Server**
- **Web Server**
- **DNS**
- **Load Balancer**
- **Monitoring**


## Learning Objectives

- Draw a diagram covering the web stack you built with the sysadmin/devops track projects.
- Explain the function of each component in the infrastructure.
- Discuss system redundancy and its importance.
- Understand and explain key acronyms such as LAMP, SPOF, and QPS.

## Tasks

1. **Simple Web Stack**
   - Design a one-server web infrastructure that hosts the website reachable via `www.foobar.com`.

2. **Distributed Web Infrastructure**
   - Design a three-server web infrastructure that hosts `www.foobar.com`.

3. **Secured and Monitored Web Infrastructure**
   - Create a three-server web infrastructure that is secured, serves encrypted traffic, and is monitored.

4. **Scale Up**
   - Develop a web infrastructure that scales up components effectively.
